# Code of Conduct

This is a small, single-maintainer hobby project, but the same basic
expectations apply as anywhere else: be respectful, assume good faith, and
keep discussion focused on the technical problem at hand (Modbus
registers, entity behavior, bugs, feature requests).

In short, don't be a jerk. Harassment, personal attacks, discriminatory
language or comments, and deliberately derailing issues/PRs into
off-topic arguments aren't welcome here.

If someone's behavior in this repository's issues, PRs, or discussions is
a problem, open an issue tagged for the maintainer's attention, or - if
that doesn't feel appropriate given the nature of the complaint - contact
the maintainer directly via their GitHub profile. Reports are handled
case by case; possible outcomes include a warning, edited/removed
comments, or blocking further participation.

This is adapted in spirit (not verbatim) from the
[Contributor Covenant](https://www.contributor-covenant.org/), scaled
down to fit a project this size.
